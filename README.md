# Cartório Virtual

App mobile premium para cartões de relacionamento com design neomórfico, gradientes prismáticos e animações fluidas.

## ✨ Features

- **Design Premium**: Neomorfismo com backdrop blur e gradientes pink/gold
- **Micro-animações**: Heartbeat, float, shimmer, scale
- **Cartões 3D**: Hover elevation com bordas coloridas por nível
- **PDF Export**: Download direto do cartão em alta resolução
- **Preview Full-screen**: Visualização antes de baixar
- **Bottom Nav**: Navegação fixa com indicators
- **FAB Buttons**: Ações flutuantes com efeitos
- **localStorage**: Persistência de cartões
- **Mobile-First**: Responsivo até 440px

## 📱 Níveis de Relacionamento

- 💘 Namorando
- 💍 Noivado
- 👰 Casamento
- 🤝 União Estável
